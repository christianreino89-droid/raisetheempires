[![Coverage badge](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/christianreino89-droid/raisetheempires/python-coverage-comment-action-data/endpoint.json)](https://htmlpreview.github.io/?https://github.com/christianreino89-droid/raisetheempires/blob/python-coverage-comment-action-data/htmlcov/index.html)

Using this one will allow you to [customize](https://shields.io/endpoint) the look of your badge.
